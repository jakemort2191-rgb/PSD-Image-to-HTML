# PSD-Image-to-HTML
A practice project converting a design or image into a webpage using HTML and CSS, focusing on layout, spacing, typography and responsive design.
# PSD / Image to HTML

## About This Project

This project is part of my software and web development course. I'm practising how to turn a visual design or reference image into a working webpage using HTML and CSS.

The aim is to recreate the layout as closely as possible while making sure the page is well structured, looks consistent and works across different screen sizes.

## What I'm Working On

- **HTML structure** – breaking the design down into sections and building the page using appropriate HTML elements.
- **CSS styling** – matching colours, fonts, backgrounds, borders and other visual details.
- **Layout** – using Flexbox or Grid to position elements and recreate the original design.
- **Spacing and alignment** – adjusting margins, padding and gaps to get the layout looking right.
- **Images and assets** – adding and positioning images to match the reference design.
- **Typography** – matching font sizes, weights, line heights and text alignment.
- **Responsive design** – adapting the page so it works on different screen sizes.
- **Attention to detail** – comparing the finished page with the original design and making improvements where needed.

## Technologies Used

- HTML5
- CSS3

## What I've Learned

This project gives me the opportunity to practise turning a visual design into an actual webpage. I'm learning how to break a design into smaller sections, translate those sections into HTML and use CSS to recreate the layout.

I'm also learning that getting a page to look right takes more than just writing the code. Comparing the result with the original design and making small adjustments is an important part of the process.

## How to View the Project

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Compare the webpage with the original design or reference image.
